# Logotypy spółek

Wrzuć tutaj pliki logo (PNG z przezroczystym tłem albo SVG), nazwane dokładnie:

- `acme.png`   (lub `.svg`)
- `cobalt.png`
- `borealis.png`
- `dlt.png`
- `pt.png`      (Iberia)

Pliki są serwowane pod adresem `/logos/<nazwa>` i podpinane w sidebarze (pasek FIRMY)
oraz na ekranie logowania. Po wgraniu daj znać — podmienimy rysowane SVG na te obrazy.
